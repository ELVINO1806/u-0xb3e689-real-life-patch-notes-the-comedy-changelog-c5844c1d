## The entry

A one-line patch note for a bug in real life — the brain forgetting why you walked into a room, then remembering the moment you step back through the doorway. Written in the terse register of a real release note, 102 characters.

## How it works

`main.py` writes the entry line to `/output/entry.txt`. Nothing else — deterministic, standard library only.


## Why this line

The joke lands on a universal bug: walking into a room and blanking on why, then remembering the instant you leave. The version number and the deadpan "fixed a bug where" framing make it read like a shipped changelog entry, and the twist — remembering in the doorway — closes the loop in the last word.
